# fashion_ecommerce_app
AI-powered fashion e-commerce project
Project Overview
This project is an AI-assisted Fashion E-Commerce application prototype developed as part of an academic project. The application includes modern UI/UX design, product browsing, cart and checkout flow, user authentication, and order tracking features.
Features
- User Login and Signup
- Homepage
- Product Listing Page
- Product Detail Page
- Cart and Checkout
- Order Tracking
- User Profile
- Responsive UI Design

AI Tools Used
- ChatGPT
- NotebookLM
- Google Gemini
- Claude AI
- GitHub Copilot
